System Pulse — это мой второй проект в программировании, я ещё новичок в Python. Первым был антивирус, а теперь захотелось сделать что-то более серьёзное и красивое. Получился монитор системы в стиле Matrix — зелёный неон на чёрном фоне с падающим кодом, как в фильме.
По сути это альтернатива стандартному диспетчеру задач Windows, но с живыми графиками, анимациями и кучей дополнительных вкладок. Всё на Python, весь код в одном файле, писал с нуля и учился по ходу — где-то может быть не идеально, но работает и выглядит так, как я задумывал.
Что умеет: следит за процессором и оперативкой в реальном времени, показывает живые графики за последнюю минуту, даёт список топ-30 процессов с поиском, сортировкой и возможностью убить любой процесс. Есть отдельные вкладки для каждого ядра CPU, для дисков с их заполненностью, для сети с IP и MAC-адресами интерфейсов. Отдельно сделал тест скорости интернета — ping, download и upload через Cloudflare. Ещё есть страница с температурой комплектующих (если поставить LibreHardwareMonitor), информация о батарее и полная сводка о железе — ОС, процессор, видеокарта, материнка, объём RAM, MAC-адрес, uptime.
Из приятных мелочей: приложение сворачивается в системный трей со своей иконкой, при загрузке процессора выше 90% приходит уведомление Windows и играет звуковой сигнал, есть кнопка отключения звуков, а заголовок окна периодически «глитчит» случайными символами. Интерфейс полностью кастомный — своя рамка окна без стандартной Windows, боковое меню с иконками и подсветкой активного пункта, светящиеся круговые индикаторы с плавной анимацией.
Стек простой: customtkinter для интерфейса, psutil для данных о системе, matplotlib для графиков, Pillow для графики, pystray для трея, win10toast для уведомлений, winsound для звуков и pywin32 для работы с Windows. Запускается одной командой на Python 3.12, всё ставится через pip. Работает пока только на Windows.
В планах на будущее — автозагрузка, очистка оперативки, дерево процессов с родителями и детьми, экспорт отчётов в файл, поддержка нескольких цветовых тем и иконки приложений в списке процессов.
Проект открытый, лицензия MIT, можно брать и менять как угодно. Я только учусь, поэтому буду рад любой критике, идеям и баг-репортам.
